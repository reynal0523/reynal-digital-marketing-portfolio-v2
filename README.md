- Responsive layout and mobile navigation
- Services, four illustrative sample concepts, deliverables, process, about, FAQ, and contact sections

## Before publishing
1. Review the copy and confirm that every service accurately reflects your current skills.
2. Confirm email and Facebook contact links.
3. The four projects are illustrative concepts, not paid client case studies or performance claims.
4. LinkedIn is omitted until a profile URL is provided.

## Publish using GitHub Pages
1. Create a GitHub repository (for example, `reynal-digital-marketing-portfolio`).
2. Upload the contents of this folder to the repository root, including `assets/`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.
